# Frontend (`src/`)

Next.js App Router UI for Ethnogames.

| Path | Purpose |
| ---- | ------- |
| `app/` | Pages (landing, Mendicot rules, play) |
| `components/` | Lobby, game table, cards |
| `lib/` | Socket client, hooks |
| `types/game.ts` | Shared types (also used by server) |

**Agent documentation:** [../docs/client/README.md](../docs/client/README.md)

Start at `app/mendicot/play/page.tsx` for multiplayer flow.
